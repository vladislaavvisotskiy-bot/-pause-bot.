# ТЗ: Telegram Mini App «PAUSE» — UI-прототип

## 0. Задача

Собери кликабельный UI-прототип Telegram Mini App для бренда доставки обедов PAUSE. Он должен **пиксель-в-пиксель повторять приложенный макет** (скриншот `design.png` с 8 экранами) и следовать брендбуку `brand.png` (цвета, шрифты, кнопки, навигация, состояния).

**Функциональности пока нет:** никакого бэкенда, API, Google Sheets и оплаты. Все данные берутся из mock-файла. Работать должна только **навигация между экранами** и переключение табов и фильтров. Кнопки «Заказать», «Участвовать», лайки и т.п. пока просто показывают toast.

Главный приоритет — визуальная точность: отступы, шрифты, цвета, скругления, тени.

## 1. Стек

- React 18 + TypeScript + Vite
- Tailwind CSS (дизайн-токены вынести в `tailwind.config`)
- react-router-dom с `HashRouter`, потому что Telegram открывает приложение по одному URL
- Иконки: `lucide-react`, тонкие линии, `strokeWidth={1.5}`
- Telegram: подключить `https://telegram.org/js/telegram-web-app.js` в `index.html`. При старте вызвать `Telegram.WebApp.ready()` и `expand()`, выставить `setHeaderColor` и `setBackgroundColor` в цвет фона `#F4EBDD`. Если приложение открыто вне Telegram (в браузере), всё должно работать без ошибок.
- Имя пользователя брать из `Telegram.WebApp.initDataUnsafe.user.first_name`. Если его нет, использовать fallback «Алексей».

## 2. Важно про макет

- Статус-бар телефона (9:41, батарея) и шапку Telegram («Закрыть / Pause / Telegram Mini App / ⋮») **НЕ рисовать**. Их показывает сам Telegram.
- Приложение рассчитано на мобильный экран шириной 360–430px. На десктопе центрировать колонку `max-width: 430px`.
- Учитывать safe-area снизу для таб-бара: `env(safe-area-inset-bottom)`.

  - H2 24/32: цена на детальной, крупные заголовки
  - H3 20/28: заголовки секций и постов, имя в профиле
  - H4 16/24: заголовки карточек, названия блюд в списке
- **Основной текст:** `Inter` (запасной вариант `Manrope`).

- **Заголовок экрана в шапке** (Меню, Pause Club и т.д.): Playfair Display 20px, цвет `green`.

### Кнопки и элементы
- **Основная кнопка:** pill, высота 52px, фон `gold`, белый текст, справа стрелка →. Pressed-состояние чуть темнее.
- **Вторичная кнопка:** pill, фон `green`, белый текст, стрелка →.
- **Контурная кнопка:** pill, прозрачный фон, обводка 1.5px `green`, текст `green`, стрелка →.
- **Кнопка «Выйти»:** фон `chip`, текст `text`, без стрелки.
- Стрелку → на кнопках «Заказать» и «Участвовать» не ставить, если она ломает вид макета. На остальных кнопках — по брендбуку.
- **Иконки-кнопки** (48px, круг, фон `card`, обводка `border`): обычная — иконка `text`; активная — фон `green`, иконка белая; акцент — иконка `gold`; неактивная — opacity 0.4.
- **Поле ввода** (на будущее, сделать компонент `Input`): высота 48px, `rounded-xl`, фон `card`, обводка `border`. В фокусе обводка `gold`. При ошибке обводка `error` и красная иконка «!» справа.
- **Чипы:** pill, высота 34px, padding 0 16px, 14px. Активный — фон `green` с белым текстом, неактивный — фон `chip` с цветом `text`.
- **Скругления:** карточки 16px, картинки в карточках 12px, большая картинка на детальной 20px.
- **Тени:** почти без теней (`0 1px 3px rgba(40,37,31,0.05)`). Карточки отделяются цветом `card` и обводкой `border`.
- **Горизонтальный отступ экрана:** 20px.

### Общие компоненты
- **`ScreenHeader`:** фон `bg`. Стрелка «назад» (ChevronLeft) слева, заголовок по центру, справа слот под иконку (⋮, фильтр, сердце, шестерёнка). Все иконки и заголовок цвета `green`. Кнопка «назад» делает `navigate(-1)`, на внутренних экранах дополнительно показывается нативная `Telegram.WebApp.BackButton`.
- **`TabBar`** (по брендбуку, **отличается от макета**): тёмно-зелёная панель с фоном `green`, прижата к низу, верхние углы скруглены на 20px, учитывает safe-area. Пять пунктов: Главная (Home), Меню (UtensilsCrossed или LayoutList), Club (Users), Послания (Mail), Профиль (User). Иконка 24px с подписью 12px под ней, без капса. Активный пункт `gold`, неактивные `nav-inactive`. Иконки одного стиля, тонкие, `strokeWidth={1.5}`. На сплэше и детальной блюда таб-бара нет.
- **`Chips`:** горизонтальный скролл без скроллбара, gap 8px.
- **Иконки:** `lucide-react`, `strokeWidth={1.5}`, минималистичные и в одном стиле.

### Состояния интерфейса (сделать компоненты и показать их на заглушках)
- **Загрузка:** карточка `card` со спиннером из точек, «Загрузка…» (H4) и «Пожалуйста, подождите» (Caption, muted). Показывать ~600 мс при первом открытии экранов «Меню» и «Послания», чтобы было видно, как это выглядит.
- **Пусто:** иконка листа, «Пока ничего нет», «Здесь появятся ваши заказы, послания и публикации». Использовать, если фильтр чипов даёт пустой список (например, «Супы»).
- **Ошибка:** красная иконка «!» в круге, «Что-то пошло не так», «Попробуйте ещё раз», золотая кнопка «Повторить».
- **Toast «Успешно»:** светлая карточка с зелёной обводкой, круглая зелёная иконка ✓, «Успешно» и «Действие выполнено», крестик справа.
- **Toast «Вы получили послание»:** тёмно-зелёная плашка `green`, белая иконка конверта, белый текст, крестик.
- Toast появляется сверху, исчезает через 3 секунды. Нерабочие кнопки («Заказать», «Участвовать», «Выйти», лайки) показывают toast «Успешно / Скоро будет доступно».

### Декоративные детали брендбука

## 8. Критерии готовности

1. `npm run dev` запускается, в браузере при ширине 390px все 8 экранов выглядят как на макете.
2. Все переходы работают: сплэш → главная, таб-бар, быстрые действия, карточки меню → детальная, назад.
3. Чипы переключаются и фильтруют списки.
4. Нет ошибок в консоли, в том числе вне Telegram.
5. `npm run build` собирается без ошибок, чтобы можно было задеплоить (например, на Vercel) и подключить URL к боту через BotFather.

После сборки сравни каждый экран с макетом и поправь расхождения в отступах, размерах шрифтов и цветах.
